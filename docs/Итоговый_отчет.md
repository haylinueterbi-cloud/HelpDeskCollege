ПМ.06 «Сопровождение информационных систем»

Тема проекта: Разработка учебного прототипа информационной системы HelpDeskCollege.

1. Введение

Целью учебной практики является получение практических навыков сопровождения информационных систем, работы с базами данных, тестирования программного обеспечения и подготовки технической документации.

В рамках практической работы был разработан учебный прототип системы HelpDeskCollege, предназначенной для регистрации и сопровождения заявок на техническую поддержку в образовательной организации.

2. Используемые программные средства

В ходе выполнения проекта использовались:

- Visual Studio Code — разработка веб-интерфейса;
- Microsoft SQL Server — управление базой данных;
- SQL Server Management Studio — создание и проверка базы данных;
- HTML — создание структуры веб-страницы;
- CSS — оформление интерфейса;
- JavaScript — реализация интерактивных функций.

3. Выполненные работы

В процессе разработки проекта были выполнены следующие действия:

1. Создана структура проекта HelpDeskCollege.
2. Разработан веб-интерфейс системы.
3. Реализованы просмотр, поиск, фильтрация, добавление и изменение статусов заявок.
4. Настроено сохранение демонстрационных данных в LocalStorage браузера.
5. Создана база данных HelpDeskCollege в Microsoft SQL Server.
6. Созданы таблицы Categories, Users, Requests и RequestHistory.
7. Добавлены категории, пользователи и тестовые заявки.
8. Выполнено изменение статуса заявки и добавлена запись в историю изменений.
9. Создана полная резервная копия базы данных.
10. Выполнена проверка резервной копии командой RESTORE VERIFYONLY.
11. Подготовлена техническая документация проекта.

4. Результаты работы

В результате выполнения практической работы получен учебный прототип системы HelpDeskCollege, позволяющий демонстрировать основные операции учёта и сопровождения заявок.

Создана база данных для хранения сведений о пользователях, категориях, заявках и истории изменений.

Разработанный веб-интерфейс позволяет выполнять основные операции с демонстрационными заявками и сохранять их состояние в браузере.

5. Вывод

В ходе учебной практики были закреплены навыки разработки веб-интерфейсов, работы с SQL Server, создания таблиц и выполнения SQL-запросов.

Также были получены практические навыки проверки программного обеспечения, резервного копирования базы данных и подготовки технической документации.

Поставленная учебная задача по созданию прототипа системы регистрации заявок выполнена в части реализованных и проверенных функций.

6. Ограничения проекта

Веб-интерфейс и база данных SQL Server на текущем этапе работают отдельно. Интеграция через серверное приложение/API не реализована.

Импорт исходного файла leads.csv и пробное восстановление резервной копии в рамках выполненных действий не проводились.
