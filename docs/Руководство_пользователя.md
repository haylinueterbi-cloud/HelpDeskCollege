Информационная система HelpDeskCollege

1. Назначение системы

HelpDeskCollege — учебный прототип информационной системы для регистрации и сопровождения заявок на техническую поддержку в образовательной организации.

Система предназначена для упрощения учёта обращений пользователей, контроля их статусов и просмотра текущего состояния заявок.

2. Запуск системы

1. Открыть папку проекта HelpDeskCollege.
2. Найти файл "index.html".
3. Открыть его в браузере.
4. После загрузки появится главная панель управления.

3. Основные возможности

Система предоставляет следующие функции:

- просмотр списка заявок;
- просмотр общего количества заявок;
- отображение количества новых заявок;
- отображение заявок, находящихся в работе;
- отображение завершённых заявок;
- поиск заявок по названию;
- фильтрация заявок по статусу;
- добавление новых заявок;
- изменение статуса заявки;
- удаление заявок.

4. Работа с заявками

Просмотр заявок

На главной странице отображается таблица с зарегистрированными обращениями. В ней указаны номер, название, категория, статус и приоритет заявки.

Добавление заявки

1. Нажать кнопку «Новая заявка».
2. Ввести название обращения.
3. Указать категорию.
4. Подтвердить добавление.

Новая заявка появится в общем списке со статусом «Новая».

Изменение статуса

В строке нужной заявки выбрать новый статус из выпадающего списка. После изменения статистика обновится автоматически.

Поиск и фильтрация

Для поиска использовать поле поиска. Для отбора заявок по состоянию использовать фильтр статусов.

Удаление заявки

Нажать кнопку удаления в строке нужной заявки и подтвердить действие.

5. Хранение данных

Демонстрационный веб-интерфейс использует LocalStorage браузера для сохранения изменений между сеансами.

База данных SQL Server HelpDeskCollege создана отдельно и содержит таблицы Categories, Users, Requests и RequestHistory.

На текущем этапе прямое подключение веб-интерфейса к SQL Server не реализовано.

6. Рекомендации пользователю

- Перед удалением заявки проверять её номер и название.
- Указывать понятные названия обращений.
- Своевременно обновлять статусы.
- Не очищать данные браузера, если необходимо сохранить демонстрационные заявки.

7. Заключение

HelpDeskCollege представляет собой учебный прототип системы сопровождения заявок, демонстрирующий основные операции учёта и обработки обращений пользователей.
