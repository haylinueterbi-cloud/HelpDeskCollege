Техническое описание базы данных HelpDeskCollege

1. Общие сведения

Для хранения информации учебного проекта HelpDeskCollege используется система управления базами данных Microsoft SQL Server.

Название базы данных: "HelpDeskCollege".

База предназначена для хранения сведений о категориях обращений, пользователях, заявках и истории изменения их статусов.

2. Структура базы данных

База данных содержит четыре основные таблицы.

2.1. Таблица Categories

Предназначена для хранения категорий технических обращений.

В системе предусмотрены следующие категории:

- Оборудование;
- Программное обеспечение;
- Сеть;
- Доступ.

2.2. Таблица Users

Предназначена для хранения информации о пользователях системы.

В базе созданы три учётные записи:

- Admin — администратор системы;
- Operator — оператор;
- Specialist — исполнитель.

2.3. Таблица Requests

Предназначена для хранения заявок на техническую поддержку.

В таблице содержатся сведения о заявках, включая их идентификаторы, статусы и приоритеты.

В базе созданы пять первоначальных заявок с идентификаторами 1001–1005.

2.4. Таблица RequestHistory

Предназначена для хранения истории изменения заявок.

Основные поля:

Поле| Тип данных| Назначение
HistoryID| int| Идентификатор записи истории
RequestID| int| Идентификатор заявки
ChangedBy| int| Идентификатор пользователя
OldStatus| nvarchar| Предыдущий статус
NewStatus| nvarchar| Новый статус
Comment| nvarchar| Комментарий
ChangedAt| datetime2| Дата и время изменения

3. Связи и назначение таблиц

Таблицы Categories, Users и Requests обеспечивают хранение основных данных системы.

Таблица RequestHistory используется для фиксации изменений статусов заявок и указания пользователя, выполнившего изменение.

4. Резервное копирование

Для защиты данных создана полная резервная копия базы данных.

Имя файла: "HelpDeskCollege_backup.bak".

Расположение:

"C:\Program Files\Microsoft SQL Server\MSSQL17.MSSQLSERVER\MSSQL\Backup\"

Проверка резервного файла выполнена командой "RESTORE VERIFYONLY". SQL Server сообщил, что резервный набор правильный.

5. Заключение

Созданная база данных обеспечивает хранение основных сведений, необходимых для учебного прототипа HelpDeskCollege, и содержит отдельную таблицу для учёта истории изменений заявок.
